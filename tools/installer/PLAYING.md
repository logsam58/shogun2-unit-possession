# Shogun 2 First-Person Mod v0.28

Launch the original Shogun 2 normally through Steam. In a single-player land
battle, select a friendly unit and press **F9**. At the closest RTS zoom, point
the mouse cursor at the soldier you want; from higher up, one is picked for you.
**F10** or **Escape** returns to your previous RTS view.

| Key | Action |
| --- | --- |
| WASD / Shift | Move / run; W + Shift toward an enemy attempts a native charge |
| P / wheel / hold middle mouse | First or third person / camera distance / orbit in third person |
| RMB / LMB | Ready weapon / fire; hold and release LMB for bow draw strength |
| Shown LMB or RMB prompt | Time the indicated click during melee |
| 1 | Toggle the whole unit's native melee/ranged mode, where supported |
| Q | Move or attack where aimed; hold and drag for formation width; double-tap to run |
| E | Stop |
| Z | Hold your current position and facing; double-tap to run there |
| C | Follow and form up beside you, running to catch up |
| R | Hold Fire / Fire at Will / Fire on Command |
| T / G | Select ability or special ammo / activate; aim at friendlies for targeted abilities |
| M | Native unit mount/dismount, where supported |
| F, then W / S | Start climbing a castle wall, then climb up / down |
| K | Hide/show RTS and possession HUD; melee prompts remain visible |
| F12 | Disable the mod until the game restarts |

Close the game before an update or uninstall. Use **Windows Settings → Apps →
Installed apps → Shogun 2 First-Person Mod → Uninstall** to remove this setup.
Unknown replacement files are preserved. Earlier snapshots remain in the setup
records folder's `rollback` directory; uninstall does not delete runtime caches.

Battle crashes, crowd slowdowns with Ultra units, and some first-person weapon
clipping remain known limitations. Single-player land battles and sieges are the
intended use; multiplayer, overhaul compatibility and ship possession are not
promised. The separate diagnostics recorder is not part of this setup.
