# Unit Possession — Test173

F12 no longer disables the mod, stops QTE or releases possession. It passes
through normally. Use F10 or Escape to return to the RTS camera. To stop loading
the mod entirely, close the game and disable its entry in the launcher.

This build retains Test172's engine compatibility checks and local-resource
preparation. Artwork, fonts, ability icons and optional voice come from the
player's own game. Other controls and gameplay mechanics are unchanged.

Keep one Unit Possession entry enabled. The publisher filename remains
shogun2_unit_possession_workshop165.pack for the existing Workshop item.
Use the original Windows x86 Steam game. Existing charge/climb, visual and
crash limitations remain; naval possession and multiplayer are unsupported.

No recorder, debugger, growing gameplay logs or automatic crash dumps are
included. Ordinary local resource/code caches remain necessary.
