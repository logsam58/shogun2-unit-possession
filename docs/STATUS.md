# Status

**v1.0** uses main as the sole maintained branch and the local-resource method for every player setup. It promotes the owner-accepted Test159 gameplay. The exact adapter, HUD, QTE and native extractor are retained; product metadata, loader and setup packaging are updated. The GitHub repository remains private until the owner chooses to open access.

The owner accepted Test159 after a manual clean-install/game trial. Installed and recorded backing-file identities matched, but the formal preplay native-hook/capture gate was missed. That gate is not retrospectively claimed, and individual unit/map coverage was not specified. The v1.0 wrapper has fresh offline validation, not a new live acceptance.

Charging and castle wall climbing are intermittent known bugs. Crashes, Ultra crowd slowdown, clipping and isolated enemy acquisition remain open. Release packaging changes do not fix them.

The release work did not replace the owner's installed v0.28/Test159, change recorder configuration, or alter game/settings/CPU files. Previous published tags/releases remain immutable. Earlier embedded-resource artifacts remain private historical material; the new code-only downloads do not convert history.
