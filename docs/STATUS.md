# Status

v0.32 publishes the accepted Test166 Workshop runtime and its matching source.
Subscribe, enable it in the launcher, and start through Steam. Third person is
the default; P changes perspective. There is no installer, external script,
camera chooser or Steam configuration step in this release.

The Workshop item has been updated and its downloaded bytes verified. The
owner accepted an in-game trial. Test166's formal loaded-hash/hook gate was
not completed; the exact scope is recorded in [validation](../VALIDATION.md).
GitHub remains private until its owner changes visibility. main is the only
maintained branch. Historical releases remain unchanged.

The player pack contains native code, bootstrap and notices, with resources
prepared from each owned game. It includes no external recorder/debugger and
does not write routine gameplay, input or QTE disk logs. Required caches still
use storage; old archives and unknown files are not automatically deleted.

Support is single-player land battles and sieges. Naval possession is planned
for later; multiplayer, including Versus and campaign drop-in, is under
consideration. Charging and climbing remain intermittent. Crashes, visual bugs,
some first-person clipping and Ultra multi-army slowdowns remain possible.

See [release identity](current-release.json), [release notes](releases/v0.32.md),
[known issues](KNOWN_ISSUES.md), and [storage details](public-release/WORKSHOP166.md).
