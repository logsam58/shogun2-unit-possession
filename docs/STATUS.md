# Status

GitHub v0.33 contains the exact Test173 pack and matching source. Test173 removes
F12 as a disable/release key and retains the compatibility work from Test172.
Its offline checks passed; live Test173 acceptance is pending. The owner
reported Test172 worked in game. These are separate validation states.

The last verified Steam upload is Test172. This GitHub release does not update
Steam. main remains the only maintained branch; repository visibility is
unchanged. The owner has made the repository public.

The Workshop route needs no installer, camera chooser, script or Steam launch
option. Native resources are prepared from the owned game. Neither Bugfix nor
Shogun2 Loader is required. Other mods are checked conservatively and may still
conflict. No recorder, debugger or routine gameplay/QTE logs are shipped.
Required caches consume storage; unknown files are preserved.

Naval possession and multiplayer are not implemented. Versus and campaign
drop-in remain under consideration. Charging/climbing are intermittent;
crashes, clipping, visual/gameplay bugs and Ultra crowd slowdowns remain open.
