# v0.25 - Shogun 2 First-Person Possession

Jump into a soldier with **F9**, fight alongside your army and give orders without leaving first person. **F10** returns you to the RTS camera. The mod includes bows, guns, thrown weapons, melee timing prompts, horseback combat, siege climbing, unit orders and a HUD styled to fit Shogun 2. The [README](../../README.md) has the full guide.

## What's changed

- Infantry and cavalry can join their formation's native charge while possessed.
- Native charge contact and horse jumps can play without immediately becoming an ordinary melee prompt.
- The accepted HUD, unit controls, firing, Rapid Advance and melee-mode toggle are retained.

**Charging is still buggy.** This is an improvement the player chose to keep, with more polish left for later. The game still decides when a charge attack or horse jump is possible. First-person arms and weapons also need visual cleanup.

## Installation

Close Shogun 2 completely before updating. Run **Shogun2-First-Person-v0.25-Setup.exe**, choose the game folder, then launch through Steam. The Windows ZIP contains the installer and player documentation; the source ZIP is for contributors.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **Mouse** | Look around |
| **Hold RMB / LMB** | Ready your ranged weapon / fire |
| **1** | Toggle the unit's native melee/ranged mode, when supported |
| **Tab** | Change available ammunition |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button when the marker reaches the highlighted zone |
| **F** near a wall | Start climbing |
| **W / S** while climbing | Climb up / down; release both to hold position |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or order a charge. Hold Q and drag left to right to set the formation, then release. |
| **E** | Stop the unit. |
| **Z** | Hold your current position and facing. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Known problems

Charging remains rough. T/G special abilities and variable bow draw are being developed separately and are not included in this release.

Ultra-sized crowded battles can still slow down badly. Other crashes, mounted-bow visuals, arm/weapon clipping and untested unit, ammo, castle and display combinations remain open. Multiplayer and overhaul mods are not confirmed to work.

The player accepted Test140 with charging marked buggy. Its formal loaded-build check was not performed. See [known problems](../KNOWN_ISSUES.md) and [technical details](v0.25-technical.md).
