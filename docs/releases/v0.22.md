# v0.22 — Shogun 2 First-Person Possession

Take control of a soldier in your army and join the battle in first person. Fight on foot or horseback, fire bows and guns, and take on enemies in melee. Give your unit orders as you fight, or press **F10** to return to commanding the army.

The mod includes melee timing prompts, shot spread based on your unit's accuracy, wall climbing for sieges, and a HUD for your unit, weapons and ammo. The [README](../../README.md) has the full guide.

v0.22 saves the latest performance improvements, along with the cleaner HUD, melee prompts and **“SHAMEFUL DISPLAY!”** when you shoot an ally. It also adds protection against one reproduced audio crash.

The latest player test was smooth throughout with **Large units, one massive army per side and maximum graphics in DX11**. Ultra units with substantial army presence can still slow down badly. Large is a good starting point for this version; performance will vary by battle and PC.

## Install

Download **Shogun2-First-Person-v0.22-Setup.exe** from the assets below. Close Shogun 2 completely, run setup and choose your game folder, then launch through Steam. In a land battle, select one of your units and press **F9**.

Use the Windows ZIP if you'd like the installer and documentation together. The source ZIP is for contributors.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **Mouse** | Look around |
| **Hold RMB / LMB** | Ready your ranged weapon / fire |
| **1 / 2** | Choose melee / ranged equipment |
| **Tab** | Change available ammunition |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button when the marker reaches the highlighted zone |
| **F** near a wall | Start climbing |
| **W / S** while climbing | Climb up / down; release both to hold position |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or charge. Hold Q and drag left to right to set the formation, then release. |
| **E** | Stop. |
| **Z** | Hold the position and facing you have when you press it. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Known problems

Other crashes are still being investigated. The smooth Large-unit test does not establish stability or smooth performance in every battle. Ultra-size crowded battles remain a known problem. Mounted-bow visuals and some weapon or arm clipping also need work. This is intended for single-player land battles and sieges; not every unit, ammo type or castle layout has been tested, and multiplayer and overhaul mods aren't confirmed to work.

Read the [known problems](../KNOWN_ISSUES.md) for help with issues. Build details, test results and ongoing investigations are in the [technical notes](v0.22-technical.md).
