# v0.23 — Shogun 2 First-Person Possession

Jump into a soldier with **F9**, fight alongside your army and give orders without leaving first person. **F10** returns you to the RTS camera. The mod includes bows, guns, melee timing prompts, horseback combat, siege climbing and the native-style HUD. The [README](../../README.md) has the full guide.

Your unit can now form up and fire without waiting for you to stand in its formation. You keep the unit's shared condition while controlling your soldier separately. Leaving possession restores normal squad control.

Possession starts facing the soldier's direction and keeps an existing walk or run going. Melee view follows the opening animation before allowing limited head-look. Follow Me gives one acknowledgement per order instead of repeating it with every movement update.

## Installation

Close Shogun 2 completely before updating, run **Shogun2-First-Person-v0.23-Setup.exe**, choose the game folder, then launch through Steam. The Windows ZIP contains the installer and player documentation; the source ZIP is for contributors. The README links the latest published download.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **Mouse** | Look around |
| **Hold RMB / LMB** | Ready your ranged weapon / fire |
| **1 / 2** | Choose melee / ranged equipment |
| **Tab** | Change available ammunition |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button when the marker reaches the highlighted zone |
| **F** near a wall | Start climbing |
| **W / S** while climbing | Climb up / down; release both to hold position |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or charge. Hold Q and drag left to right to set the formation, then release. |
| **E** | Stop. |
| **Z** | Hold the position and facing you have when you press it. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Known problems

The player confirmed Test130 gameplay worked and selected it for v0.23, but the session also crashed. The cause remains unresolved; this version does not claim to fix it.

Ultra-sized crowded battles can still slow down badly. Mounted-bow visuals, some arm/weapon clipping and untested unit, ammo, castle and display combinations remain open. Multiplayer and overhaul mods are not confirmed to work.

See [known problems](../KNOWN_ISSUES.md) and [technical notes](v0.23-technical.md) for evidence and limits.
