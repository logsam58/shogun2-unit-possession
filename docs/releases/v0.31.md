# v0.31 — Shogun 2 Unit Possession

The camera chooser now includes a quick-start guide: a WASD diagram, how to possess and return to RTS, combat inputs, camera controls, abilities and unit orders.

The chooser runs before the original game starts. Choose First-Person or Third-Person to launch; closing the chooser cancels. The game loader no longer opens a popup over Shogun 2's fullscreen window.

This requires one-time Steam setup: after installation, paste the launch-option line supplied by the wizard into **Shogun 2 > Properties > Launch Options**. Setup also saves the exact line in Steam-Launch-Options.txt in the installed mod folder. Keep existing game arguments after `%command%`. Remove this line before uninstalling. Another custom launch wrapper needs compatibility review.

The helper preserves Steam context, the original command line and working directory. Without the helper option, the game launches in first person with no popup; P still switches during possession. The installer prepares game resources locally as before and recognizes the exact v0.30 installation for upgrade and rollback.

Gameplay source is unchanged. Attack charging remains partly broken and unreliable; castle climbing is intermittent. Crashes, Ultra crowd slowdown and visual issues remain open. Naval possession and multiplayer are not implemented. See [known issues](../KNOWN_ISSUES.md).

This update has offline validation but has not been installed or live-tested on the owner's game. The published v0.30 release and downloads remain unchanged. See [startup investigation and test boundaries](../public-release/STARTUP161.md).

Offline checks cover the actual guide, launch ordering, inherited arguments/context, and standard install/rollback. See [v0.31 validation](../public-release/V0_31_VALIDATION.json) for fresh checks, retained gameplay evidence and live-test limits.
