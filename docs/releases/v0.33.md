# v0.33 — Shogun 2 Unit Possession

This update helps the mod work alongside other mods and on more installations.
The controls and combat remain the same, except **F12 no longer disables the
mod or ends possession/QTE**. Use F10 or Escape to return to RTS.

## What's changed

- The original game and the reviewed Bugfix engine are supported. Other engine
  edits can pass when the code and layouts possession needs remain compatible.
  Conflicting changes still refuse with an error; arbitrary DLL support is not
  guaranteed. You do not need to install Bugfix or Shogun2 Loader.
- Custom units without a stock unit card can keep the rest of the HUD.
- Supported older PFH2/PFH3 packs no longer fail just for using that format.
- Startup can preserve one enabled UI-mod root. Different competing UI roots,
  or another mod preventing our bootstrap from running, can still conflict.
- Compatible native fonts can come from the installed language pack. The HUD
  remains English, and not every language has been tested. English advisor
  audio and its decoder are optional; missing voice does not block possession.
- Early startup failures restore the game's menu callbacks where possible and
  report a bounded error. Routine gameplay/input/QTE logs remain disabled.
- F12 passes through normally. F10/Escape still return to your RTS camera.

## Downloads and Steam status

**No installer is provided.** This release contains a Workshop-pack archive,
matching source, a manifest and checksums. Game artwork, fonts and audio are
prepared from each player's own game; no recorder, debugger or dump collector
is shipped. The existing Miles audio guard remains.

The GitHub archive contains the exact **Test173** pack. The last independently
verified Steam upload is **Test172**. Publishing this GitHub release does not
update the [Steam Workshop item](https://steamcommunity.com/sharedfiles/filedetails/?id=3825625050).
Keep one possession pack enabled and restart the game after changing it.

Test172 received the owner's successful manual gameplay report. Test173 passed
the native and package checks after removing F12; its loaded-build gate and
live gameplay acceptance are still pending. No new game test or native rebuild
was performed just to publish this version.

## Known issues

**Naval possession and multiplayer are not implemented.** Versus and campaign
drop-in remain under consideration. Charging and wall climbing are intermittent.
Crashes, first-person clipping, other visual/gameplay bugs and serious slowdown
in large Ultra-unit battles remain possible. Compatibility checks do not prove
every interaction with every mod.
