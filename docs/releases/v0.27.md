# v0.27 - Shogun 2 First-Person Possession

Charging works! Run or gallop toward an enemy with **W + Shift** and let the game take over the approach and attack. Your unit still follows its own orders. The charge uses Shogun 2's own attacks and defenses, with the usual chance that your opponent survives or counters you.

**K** also hides the first-person HUD now. Hide it in RTS, jump into a soldier, and it stays hidden. Melee timing prompts and their mouse-button indicator remain visible.

This release completes the charging checkpoint after the player's successful Test149 battle. It also includes unit abilities, variable bow strength, the cropped “Shameful display!” callout and the existing unit controls.

## Install

Close the game, run **Shogun2-First-Person-v0.27-Setup.exe**, choose the game folder, then launch through Steam. The Windows ZIP includes setup and player documentation. The source ZIP is for contributors.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **W + Shift toward an enemy** | Start a personal charge; the game handles the engagement |
| **Mouse** | Look around |
| **Hold RMB** | Ready your ranged weapon |
| **LMB** | Fire guns and thrown weapons; hold then release for bow strength |
| **1** | Toggle the unit's native melee/ranged mode, when supported |
| **T / G** | Cycle / use the unit's abilities and special ammunition; aim at a friendly unit for Inspire |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button as the marker reaches the highlighted zone |
| **F near a wall; W / S** | Start climbing; climb up / down |
| **K** | Hide/show the HUD; melee prompts remain visible |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or order a charge. Hold and drag to set a formation. |
| **E** | Stop the unit. |
| **Z** | Hold your current position and facing. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Still being worked on

First-person weapon and arm clipping, mounted-bow presentation, enemy targeting when you are away from your unit, Ultra-sized crowded battles and other crash paths remain open. Bow sound still follows the native draw animation. Multiplayer and overhaul mods haven't been confirmed to work.
