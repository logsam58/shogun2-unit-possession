# v0.24 - Shogun 2 First-Person Possession

Jump into a soldier with **F9**, fight alongside your army and give orders without leaving first person. **F10** returns you to the RTS camera. The mod includes bows, guns, thrown weapons, melee timing prompts, horseback combat, siege climbing, unit orders and a HUD styled to fit Shogun 2. The [README](../../README.md) has the full guide.

## What's changed

- **Rapid Advance:** keep walking available, and hold Shift to run at the unit's boosted pace.
- **Enemy targeting:** Q can pick an enemy through friendly troops in the foreground.
- **Melee mode:** press **1** to toggle the whole unit's native melee mode. Units without an alternative ignore it; **2** no longer switches weapons. The HUD uses the game's own mode artwork.
- **Weapon presentation:** keep the accepted melee combat behavior while restoring ordinary movement animations.
- **Crash correction:** cover one captured fault in a detached soldier's advance task. Other crashes remain under investigation.

Your unit still forms up and fires while you move away from its formation. The existing camera, HUD, QTE, unit orders, performance work and cropped **SHAMEFUL DISPLAY!** friendly-fire callout are retained.

**The first-person weapon view still needs work.** Some arm/weapon poses and clipping are imperfect. This version was accepted with that caveat, and the visual cleanup is deferred.

## Installation

Close Shogun 2 completely before updating. Run **Shogun2-First-Person-v0.24-Setup.exe**, choose the game folder, then launch through Steam. The Windows ZIP contains the installer and player documentation; the source ZIP is for contributors.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **Mouse** | Look around |
| **Hold RMB / LMB** | Ready your ranged weapon / fire |
| **1** | Toggle the unit's native melee/ranged mode, when supported |
| **Tab** | Change available ammunition |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button when the marker reaches the highlighted zone |
| **F** near a wall | Start climbing |
| **W / S** while climbing | Climb up / down; release both to hold position |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or order a charge. Hold Q and drag left to right to set the formation, then release. |
| **E** | Stop the unit. |
| **Z** | Hold your current position and facing. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Known problems

Your formation can receive native attack/charge orders, but the possessed soldier's own infantry/cavalry charge behavior still needs work. T/G special abilities and variable bow draw are later tasks, not part of this release.

Ultra-sized crowded battles can still slow down badly. Other crashes, mounted-bow visuals, arm/weapon clipping and untested unit, ammo, castle and display combinations remain open. Multiplayer and overhaul mods are not confirmed to work.

The accepted player test followed verified loaded files and active recording. That result is not a guarantee for every battle or unit. See [known problems](../KNOWN_ISSUES.md) and [technical details](v0.24-technical.md).
