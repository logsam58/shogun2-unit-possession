# v0.30 — Shogun 2 Unit Possession

Command the army, then join the fight in first or third person. Select a unit and press F9 to take control of a soldier; F10 returns to the RTS camera.

**Naval battles do not support possession.** Naval support is planned for a later update. **Multiplayer is not implemented:** Versus and campaign drop-in support are under consideration. Expect visual bugs, gameplay bugs and occasional crashes. Current support is single-player land battles and sieges.

## What changed

- The mod and repository are now named **Shogun 2 Unit Possession**.
- Each game launch shows a small window asking for a **Third-Person** or **First-Person** default. Third-Person is highlighted; closing the window uses Third-Person. New possessions start in that view. Press P to switch while possessing.
- The choice lasts for the game process. It does not alter the game's settings or install a separate launcher.

## Install and play

Download **Shogun2-Unit-Possession-v0.30-Setup.exe** from Assets. Close Shogun 2, run setup, choose the original Windows Steam installation, then launch through Steam. No Python, compiler or separate media tools are needed to play. The installer is unsigned. The repository remains private until its owner opens access.

Setup prepares artwork, unit cards, ability/status icons, fonts and the cropped advisor voice from your own game. Those resources are not bundled in the download. The supported English local_en.pack is required; Windows N needs the Media Feature Pack. Windows Installed apps provides uninstall with rollback records retained.

## Playing

Use bows, guns, thrown weapons and native melee encounters. Give formation/move/attack orders with Q, Stop with E, Hold Here with Z, Follow Me with C and fire orders with R. Toggle native weapon mode with 1, select abilities/ammunition with T and activate with G. P switches camera; scroll and middle mouse control third-person distance/orbit. See the [full feature and controls guide](../../README.md).

Charging and castle wall climbing are intermittent. Battle crashes, Ultra multi-army slowdowns, some first-person clipping and isolated enemy acquisition remain unresolved. See [known issues](../KNOWN_ISSUES.md). This release does not claim to fix them.
