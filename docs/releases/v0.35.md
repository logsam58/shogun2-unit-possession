# v0.35 — Unit Possession source

This source tag contains Revision51 for PC and Steam Deck. It adds custom and
replacement unit portraits, a compact possession HUD with a unit ammo meter,
and eight-direction Deck formation placement with group rotation. The owner
confirmed the new trackpad controls and a custom portrait in separate Deck tests.

The comparison baseline is the November 3 Workshop update, Revision39.
See the [Steam-formatted change notes](https://github.com/logsam58/shogun2-unit-possession/blob/v0.35/docs/workshop/changelog-v0.35.bbcode.txt)
and the [published Workshop history](https://steamcommunity.com/sharedfiles/filedetails/changelog/3825625050).

Build from an owned game using the [combined build guide](../../BUILD_STEAM_DECK.md).
The [validation record](../public-release/V0_35_VALIDATION.json) separates offline
checks, the owner’s Deck test and the public Workshop version. The Git tag is
source-only. Steam Workshop remains the player download.
