# v0.32 — development candidate

Not released or live-tested yet.

- Setup connects the camera chooser automatically. Exit Steam before setup; there is no script or command to paste.
- The chooser accepts Shogun 2's signed Creative Assembly launcher as well as the original game executable.
- “Shameful Display!” plays inside the game process so recordings of Shogun 2 can include it. The voice still comes from your installed game.

Existing charging/climbing, crash, crowd-performance and presentation limitations remain. See the [implementation and test boundaries](../public-release/STARTUP162.md).
