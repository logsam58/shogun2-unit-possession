# v0.32 — Shogun 2 Unit Possession

Take control of a soldier in first or third person while your army keeps
fighting. Use their weapons, give unit orders and abilities, ride cavalry and
fight through sieges. F9 enters possession, P changes perspective and F10
returns you to your RTS camera. See the [full controls](../../README.md#controls).

## What's changed

- Install through Steam Workshop: subscribe, enable the mod and play. No setup
  program, external script, camera popup or Steam launch-option edit.
- Third person is the default. Press P whenever you want first person.
- HUD art, unit cards, ability icons, fonts and the cropped “Shameful display!”
  voice are prepared automatically from your own game. They are not bundled.
- Routine gameplay, input, QTE and startup disk logs are disabled. A small live
  receipt disappears when the game exits; compatible builds share resource
  bytes where supported. Necessary caches still use space.
- The pack includes no recorder, debugger, profiler or crash-dump collector.
  The existing Miles audio guard is retained; other crashes remain unresolved.
- Friendly-fire voice playback runs in the game process so game-audio recording
  can capture it. Recording setup still determines what audio is captured.

This release uses the exact accepted Test166 Workshop pack. No gameplay binary
was rebuilt for the version label. The owner reported a successful in-game
trial; this is not a claim of every feature or long-term stability being tested.

## Play

1. [Subscribe to Shogun 2 Unit Possession](https://steamcommunity.com/sharedfiles/filedetails/?id=3825625050).
2. Enable it in Shogun 2's launcher and launch through Steam.
3. Select a friendly unit in a land battle or siege and press F9.

Restart the game after enabling, disabling or updating. Existing Workshop users
need no separate GitHub download. If coming from an older setup.exe version,
uninstall that version and remove its old camera-helper launch option before
enabling Workshop. Do not run both loaders together.

The supported original Windows Steam game and English local_en.pack are needed.
Windows N editions need the Media Feature Pack. Item/repository access remains
controlled by the owner; this release does not change visibility.

## Downloads

- **Workshop.zip**: archive of the exact Workshop pack, player instructions and
  license notices. Subscription is the normal installation route.
- **Source.zip**: matching developer source and build instructions, without game
  resources, private recordings, compiled payloads or toolchains.
- **SHA256SUMS.txt / release-manifest.json**: checksums and exact build identity.

## Known issues

**Naval battles do not support possession. Multiplayer is not implemented;**
Versus and campaign drop-in are under consideration. Charging and wall climbing
sometimes work and sometimes fail. Visual/gameplay bugs, some crashes, weapon
clipping and serious slowdowns in very large Ultra-unit battles remain possible.
Other mods replacing the same front-end root script may conflict.
