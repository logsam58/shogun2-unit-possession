# v0.23 technical notes

## Accepted gameplay

v0.23 retains the exact Test130 adapter, HUD and QTE binaries and complete native output source. Only release metadata, predecessor recognition and packaging change during promotion. Installed Test130 files stay in place.

The user reported that it worked after the Test130 battle gate verified exact loaded components, native hooks, Steam context and active audio guard. The user also reported a crash and selected this checkpoint for the next version. Recorder/debugger were off. Acceptance covers the reported gameplay result, not crash safety or every roster/map; this crash has no established cause or correlated stack.

## Independent soldier control

`unit_detach130.h` separates actor+0x3b4 primary SQUAD participation from actor+0x214 unit/stat ownership. Native removal and insertion run at unit callbacks. Restoration requires current actor/unit identity, original entity-roster membership and registered squad lists. Insertion/transfer and regroup-candidate guards prevent automatic reassignment. Master entity rosters, secondary physical groups, camera holders and mount/passenger links remain intact.

`unit_detach_combat130.h` retains personal combat tasks and supplies the actor's position/facing for two native consumers that assume squad context. Missing-squad bookkeeping is omitted only for the physically proved detached actor. Physical identity is revalidated; negative filters grant no positive authority. Deferred shutdown retains read-only compatibility and the native rejoin callback while restoration is pending. No fake SQUAD or off-thread restoration is used.

Test128/129 readiness exceptions were rejected alone. They remain complementary in the accepted source; the Test130 native aggregate fixture proves actual detachment independently of those exceptions.

Test125/126 entry facing/gait and animation-led QTE look are retained. Test127 gates Follow Me voice acknowledgements per command session while preserving native movement. Exact HUD/QTE, weapons and earlier crowd/audio-guard work remain intact. Test116/117 experiments remain excluded.
