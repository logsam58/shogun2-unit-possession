# v0.26 - Shogun 2 First-Person Possession

Fight alongside your army with **F9**, give orders from first person, and return to the RTS camera with **F10**. The mod includes bows, guns, thrown weapons, melee timing prompts, horseback combat, siege climbing and unit orders. The [README](../../README.md) has the full guide.

## What's new

- **Use your unit's abilities:** T cycles available abilities and special ammunition; G uses or ends the selected one. Abilities affect the whole unit, including your soldier, and keep the game's restrictions and cooldowns. Aim at a friendly unit to use Inspire on them.
- **Choose bow strength:** hold RMB to ready the bow, then hold and release LMB to shoot. A quick tap gives a weaker shot; holding longer reaches full strength. Guns and thrown weapons still fire on a click.
- **A small melee aiming dot** helps you point unit orders and targeted abilities, on foot or horseback.
- Hold Here uses your current position reliably, and possession can follow the same rider through a native dismount, including Stand and Fight.

Bow sounds follow the native animation again. Separating the sounds from that animation has been set aside for later; bow strength is retained.

## Installation

Close Shogun 2 completely before updating. Run **Shogun2-First-Person-v0.26-Setup.exe**, choose the game folder, then launch through Steam. The Windows ZIP contains the installer and player documentation; the source ZIP is for contributors.

## Controls

| Key | Action |
| --- | --- |
| **F9** | Possess a soldier in the selected unit |
| **F10 / Escape** | Return to your previous RTS camera view |
| **WASD / Shift** | Move / run |
| **Mouse** | Look around |
| **Hold RMB** | Ready your ranged weapon |
| **LMB** | Fire guns and thrown weapons; hold then release for bow strength |
| **1** | Toggle the unit's native melee/ranged mode, when supported |
| **T** | Cycle the unit’s available abilities and special ammunition |
| **G** | Use or end the selected ability; aim at a friendly unit for Inspire |
| **Hold Ctrl** | Crouch to fire, where supported |
| **LMB / RMB prompt** | Click the shown button when the marker reaches the highlighted zone |
| **F** near a wall | Start climbing |
| **W / S** while climbing | Climb up / down; release both to hold position |
| **F12** | Turn the mod off for the session |

## Unit orders

| Key | Order |
| --- | --- |
| **Q** | Aim at the ground to move, or at an enemy or supported breakable target to attack. Tap to walk; double-tap to run or order a charge. Hold Q and drag left to right to set the formation, then release. |
| **E** | Stop the unit. |
| **Z** | Hold your current position and facing. Tap to walk there; double-tap to run. |
| **C** | Follow you and form up beside you. Run to catch up, then match your pace. |
| **R** | Cycle Hold Fire, Fire at Will and Fire on Command. In the last mode, the unit fires when you fire. |

## Known problems

Charging is still buggy. The first-person bow draw and some weapon/arm poses need more work. Bow strength changes the shot, while the existing draw animation still starts with RMB.

Ultra-sized crowded battles can still slow down badly. Other crashes, mounted-bow visuals, clipping and untested unit, ammo, castle and display combinations remain open. Multiplayer and overhaul mods are not confirmed to work.

See [known problems](../KNOWN_ISSUES.md) and [technical details](v0.26-technical.md).
