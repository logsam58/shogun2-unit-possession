# v0.28 technical notes

v0.28 promotes the exact gameplay binaries and native/outputs source from accepted Test157. The player reported “Worked great. Everything.” after a formal loaded-hash/native-hook/capture verification in the same process. That battle ended in a captured access violation. Gameplay acceptance does not establish crash safety or universal coverage of every unit and castle. The release loader/installer is rebuilt for version metadata and has separate offline validation; it is not installed or live-tested as part of publication.

## Selection and soldier roles

At the stock RTS camera's closest zoom, F9 uses the original mouse coordinates, render unprojection and native scene query. It prefers the eligible soldier under that cursor within the selected unit; a reciprocal horse hit selects its rider. High-camera selection and native occlusion remain. No recurring selection scan was added.

The shared role policy admits the final native regular, General, officer, standard-bearer, musician and naval-leader actor classes. Each special role keeps its own configuration, actions and personal projectile record. A missing native shoot action does not grant the formation's ranged weapon. Recognizing a naval leader class does not add ship locomotion. Animal/vehicle bodies, unknown classes and invalid ownership remain excluded.

Special configurations now use the same native root/attachment policy as regular soldiers. The former posture<18 cut-off was inconsistent with native3e4850's posture domain. Both bulk and sparse QTE camera reads now accept the shared soldier policy. The exact cause of the earlier reported General rejection was not recorded; these are proved code restrictions, not a retrospective claim about that incident.

## Camera, climbing and mounting

P switches first/third person, the wheel adjusts distance, and held MMB orbits independently of WASD. Third-person input keeps a valid camera basis; yaw, pitch, orbit and distance survive new QTE pairs. First-person combat look remains limited around the animated face. Third-person death uses captured numeric poses and omits first-person eyelids; existing return bounds remain.

M dispatches the original whole-unit mount/dismount action. Camera continuity uses the same human identity, reciprocal mount, native task and current mount/dismount animation. Unit task+ba8 is validated as a count over ba0/ba4 slots. Wall entry uses the actual portal navigation location, preserving surface and coordinate-frame fields through native approach, alignment and climbing. It does not substitute a bearing pose, force a clip or guess a wall heading.

Routing keeps the existing living soldier through native empty-selection changes using the same current-lease policy in camera roster queries. New acquisition, foreign selection, serial/lifetime, environment, holder, phase and heartbeat guards remain. Death handoff does not select a replacement soldier. Native routing combat has no QTE. A new battle or retired actor does not gain authority from an old camera pointer.
