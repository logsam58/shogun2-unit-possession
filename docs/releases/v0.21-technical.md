# v0.21 technical notes

## Shipped checkpoint

v0.21 packages the exact Test122 adapter, HUD and QTE binaries. Test122 combines the published v0.20 feature base with performance changes118 through122. The release loader and installer have new version metadata and cache identity; publication does not replace the user's installed Test122 files.

The maintained source has been aligned to the actual Test122 build. The Test116 battle-clock and Test117 render-copy experiments are excluded and remain recoverable in Git history. The adapter and HUD source match the v0.20 base; QTE changes preserve its acknowledged-image input handling.

## Reduced crowd work

Foreign melee callbacks reject unrelated actors before expensive physical and reservation identity proofs. Current bounded reads share camera, participant and pose data within a single callback. Mounted paths exclude unrelated witnesses before proving reciprocal rider/mount ownership. During coordinated preparation, unrelated selector entries take a bounded address filter; possible player matches repeat the original full proof and participant reads.

There is no cross-callback identity cache or time grace. Both scope checks, current lease and unit serials, native forwarding, individual-read fallbacks and full positive ownership checks remain. No new hooks, native writes, QTE rules or unit controls were added by these performance changes.

The Test122 comparison changed only the final selector optimization on the same v0.20-plus-Test121 base. Five alternating runs of10,000 synthetic foreign preparations reduced median CPU time from183.063 to120.189ms for infantry and256.727 to130.862ms for mounted actors. Native actions were fixture stubs. These numbers describe callback cost, not game FPS.
