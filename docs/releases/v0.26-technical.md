# v0.26 technical notes

The release combines native whole-unit T/G abilities, friendly-target Inspire, native per-ability sound selection, shared same-rider dismount continuity, current-position Hold Here projection, variable bow strength and the melee aiming dot. Original game icons are reused; Tab ammunition cycling is removed in favour of T/G.

The user confirmed Test143 bow strength and friendly ability targeting and reported Test144 working, but rejected the timing of decoupled bow sound. Test145 removes both experimental bow sound hooks, actor sound TLS, LMB cue requests and handle stop processing. Bow sounds again follow the original authored animation events. No shared sound asset is changed. Decoupling is deferred; no replacement draw animation is introduced.

Bow strength retains the established release sampler, native duration/marker interpretation and one-shot speed argument. Original ballistic solver, gravity, accuracy, damage, ammo, reload and animation projectile marker remain. The35%-100% input policy is added player control, not a claim about stock RTS draw strength. Original ability restrictions, range, cooldowns and effect scheduling remain authoritative.

The preserved on-demand decoder and indexed native exports were reused for the checkpoint work and Test144 sound investigation. This rollback uses that preserved evidence.

The final receipt records fresh adapter86, loader2, complete installer/all seven interruption stages/repeat backups and Python7, separately from byte-exact retained HUD144/7 and QTE140/47. Native audio tests execute original292620/cd56e0 and42 ability selectors against explicit unit/position/voice/device providers; actual device output and all ability combinations are not simulated. The stricter runner rejects every nonzero native exit, including negative exception statuses.

## Remaining limits

Charging is still buggy. First-person weapon/arm presentation, mounted bows, Ultra crowd slowdown and other crashes remain open. User feedback is separate from a formal loaded-build/capture gate; no fresh Test144 gate was completed. No universal performance or crash safety claim is made.
