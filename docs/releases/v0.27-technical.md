# v0.27 technical notes

v0.27 promotes the exact Test149 gameplay adapter, Test148 HUD and Test146 QTE accepted by the user. Only version metadata, the loader and the installer are rebuilt. The user reported Test149 working and requested checkpoint completion and publication; no formal Test149 loaded-hash/capture gate was completed before that feedback. This is user-reported live acceptance, separate from offline validation. The release wrapper itself has not been live-tested.

## Charge correction

Physical W+Shift starts a personal charge independently of the unit's order. Original native perception, matchup range, minimum speed, eligibility and current actor ownership select a forward enemy before contact. Native human/horse/rider tasks retain approach, jump eligibility, contact, paired animation and outcome selection. The game's roles, weapon compatibility, RNG, counters and survival remain authoritative.

The reproduced fault was an early charge return in prepare(), which skipped the player's registered native pair alignment. Native pair alignment now runs first; approach-only charge movement still yields to the original task. Initiation rejects native fighting/defending/non-ground postures and applies the live native minimum separation. Outgoing charge contact waits for the actual native charge pose or horse jump; incoming native attacks always forward. The two-simulation-tick contact handoff keeps ordinary QTE from stealing the native charge. There is no forced kill, clip, casualty write, new random outcome or invented cooldown.

Expensive target proofs remain bounded to 32 candidates/2,000 roster entries at 10 Hz; committed charges do not reprobe. The existing log records numeric pose/pair/clip observations only. General proximity membership is retained: join within 4 m of another living member of the current own formation, leave beyond 8 m. These distances are mod policy, not stock engine thresholds.

## Hide UI

Native K key edges are mirrored in both RTS and possession without consuming the native input buffers. The separate visibility channel survives F9/F10 and held-key transitions. HUD panels and reticles hide; QTE and its mouse-button prompt remain independent. Existing shared gameplay/status layouts remain unchanged.

## Evidence and validation

The preserved on-demand decoder and animation companion decoded 174 of 178 selected assets with four cache hits across 244 declarations. Read-only Ghidra exports cover 18 functions plus nine indexed functions, with instruction bytes verified against the supported retail engine. These exports are decompilation evidence, not original source or independently verified ABI declarations. The native matched and charge-capable animation selectors preserve attacker/defender roles and outcomes. No claim is made that every possible weapon pairing has a charge kill or jump.

Test149's strict adapter suite passed 88 fixtures; exact retained HUD and QTE suites cover 7 and 47 fixtures. Release validation rebuilds and tests the loader and full installer, including exact Test149 and all prior predecessor upgrades, seven interrupted transaction rollbacks and repeat-install backup retention, plus seven Python tests. Payloads, local assets, source closure, installer version and package checksums are pinned in [the release receipt](v0.27-validation.json).

## Remaining work

Enemy autonomous acquisition of a separated player remains open. Resolving a selected actor's native subgroup does not prove strategic enemy selection. POV/clipping, mounted bows, very large crowded battles, other crashes and bow sound decoupling remain open. The release does not change game settings, CPU affinity, recorder configuration or the installed accepted Test149 files.
