# Diagnostics110 startup recovery

Two normal user launches after Diagnostics110 deployment failed during audio startup. Both captured first-chance and unhandled exception0x80000004 at AUDIOSES.DLL+0x61268. This is a new diagnostic regression, separate from the earlier native effects read, Miles sample-loop read and DirectSound invalid call.

Both traces show DR6 bit3 set and actual DR3 still pointing to the initially observed audio interface. The debugger's stored programmed DR3 was already zero after the wrapper pointer was cleared. The handler rejected that trap as unowned and forwarded it; the application did not handle it. The evidence establishes lost ownership of a diagnostic hardware trap. The exact kernel event/context reprogramming order that produced the disagreement is not yet established. Synthetic concurrency passes did not cover this real transition.

With the game closed, only the diagnostic executable was initially restored to the exact preceding exception-only build. Normal, handled-fault and crash capture checks passed, but its offline detach failed with Windows error5. That failed attempt remains preserved. A capture-only rebuild retains the corrected Windows event-handle ownership and disables all hardware tracing in real-game mode. Its SHA256 is4b92e66f588ebe739fbb99f0d7aa9f75136255427d8a2af6bfafa75cea682193. It passed four fresh full-session cases (normal, handled fault, native crash and safe detach), a native guard fixture verifying real-mode targets/armed threads/traps all zero, and rejection of the withdrawn deployment before mutation. This verified capture-only executable is now installed. Real startup recovery still awaits a user launch.

The withdrawn executable, temporary exact rollback and both complete startup recordings/dumps are preserved privately. The lifecycle sampler, expanded game-focused keys, audio inventory and original CPU/memory/GPU/VRAM/core capture remain. Hardware writer/destructor observations are unavailable in this capture-only mode.

The persistent watcher, autorun, recording destination and Test109 baseline are retained. No game DLL, accepted gameplay, graphics/audio preference, frozen v0.19 package or published release was changed. The agent did not launch or terminate the real game.
